# Financial Transactions Analysis Dashboard | Power BI

## Project Overview
This project analyzes financial transactions from 2022 to 2025 using Microsoft Power BI. The interactive dashboard provides insights into transaction performance, customer activity, payment methods, risk indicators, and compliance.

## Tools Used
- Microsoft Power BI Desktop
- Power Query for data preparation
- DAX for measures and KPIs (where applicable)

## Dashboard Pages

### 1. Transaction Overview
- Total transaction amount
- Total transactions
- Average transaction amount
- Total fees
- Active customers
- Monthly transaction trends
- Transaction analysis by payment method, channel, and currency

### 2. Customer & Account Analysis
Explores customer activity and account-level transaction patterns.

### 3. Risk & Fraud Analysis
Presents risk-related indicators to support further investigation. Dashboard indicators should not be interpreted as proof of fraud.

### 4. Compliance Analysis
Provides a dashboard view of compliance-related transaction information.

## Key Objectives
- Monitor transaction performance over time.
- Compare transaction amounts across payment methods and channels.
- Understand customer and account activity.
- Support risk monitoring and compliance analysis.

## Files Included
- `finance transactions.pbix` — Power BI report file.
- Dashboard screenshots — visual previews of the four report pages.

## How to View
Download the `.pbix` file and open it using Microsoft Power BI Desktop.

## Disclaimer
This project is intended for learning and portfolio demonstration. Findings depend on the dataset and the measures used in the report.
